# 📊 Income Prediction Model

A **Linear Regression** model that predicts per capita income using historical data from Canada.

---

## 🧠 About the Project

This project uses supervised machine learning (Linear Regression) to predict per capita income based on the year. It was built using Python and Scikit-learn, and demonstrates a complete ML workflow — from data loading and model training to prediction and export.

**Model Equation:** `Y = 828.46 * X + (-1,632,210.76)`

---

## 🛠️ Tech Stack

- Python 3
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

---

## 🚀 How to Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/income-prediction-model.git
   cd income-prediction-model
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Launch the notebook:**
   ```bash
   jupyter notebook Income_Prediction_Model.ipynb
   ```

## 📈 Model Details

| Parameter | Value |
|-----------|-------|
| Algorithm | Linear Regression |
| Coefficient (m) | 828.46 |
| Intercept (b) | -1,632,210.76 |
